3. State / Data Architecture

Three-layer design

LayerModuleResponsibility
Pureutils/grievanceUtils.jsDerivations: computeStats, filterComplaints, paginate, slaFor, breakdowns, trend. Zero side effects, zero React.
Storageservices/grievanceService.jsThe only module that touches localStorage. loadState, persistState, buildComplaint, applyStatusChange, applyAssignment, notificationForStatus.
Reactcontext/GrievanceContext.jsx
context/grievanceReducer.js		useReducer + useEffect persistence. Every screen reads the same complaints array. Dispatch actions: CREATE, STATUS, ASSIGN, READ_NOTIFICATION, READ_ALL, RESET, CLEAR.

Data flow (citizen files → officer sees)

  1. Citizen submits → buildComplaint() generates unique ID, attaches AI analysis, creates timeline entry
  2. dispatch({ type: CREATE }) prepends to state.complaints, creates citizen + officer notifications
  3. useEffect persists entire state to localStorage
  4. Officer dashboard reads the same complaints array → computeStats() recalculates all tiles
  5. Officer opens detail → same record, same timeline, same AI analysis
  6. Officer changes status → dispatch({ type: STATUS }) → citizen's tracker updates instantly
Critical invariant: there is ONE array of complaints. No page keeps a private dataset. Every statistic is derived by computeStats(), never hardcoded. The behaviour check verifies this with 101 assertions including a full citizen→officer round-trip through the real reducer.

5. Voice Recognition Implementation

Real Web Speech API — not mocked

Module: src/hooks/useSpeechRecognition.js

  • Uses window.SpeechRecognition / window.webkitSpeechRecognition
  • Continuous mode with interim results — words appear as the user speaks
  • Accumulates finalized chunks across onresult events via a ref
  • Language passed to recognition.lang: supports en-IN, hi-IN, ne-NP, gu-IN
  • Unsupported browsers get: "Speech recognition is not supported in this browser. Please use Chrome or enter your complaint manually."
  • Error messages mapped per error code: not-allowed, no-speech, audio-capture, network, aborted
  • Microphone released on unmount via recognition.abort() in a cleanup effect

Whisper integration point

Documented in the hook's JSDoc: for browsers without the Web Speech API, record audio via MediaRecorder and POST the blob to /api/voice/transcribe. The hook's return shape { transcript, language } matches what the endpoint should return, so the VoiceRecorder component needs no changes.

6. AI Integration Points

Current: keyword-based classification

Module: src/services/aiService.js

  • analyzeText(text) — matches against AI_RULES (keyword arrays per category); returns { category, priority, department, confidence, language, summary }
  • analyzeImage() — cycles through VISION_RESULTS; returns detected objects + category suggestion
  • findRelated(complaint, candidates) — scores by category match, word overlap, recency, priority; returns top 3
  • Urgency words (dangerous, urgent, flooding, etc.) escalate priority one rank
  • Language detection via Unicode script ranges (Devanagari, Gujarati, Tamil, etc.)
  • Confidence scales with text length — longer, more specific reports score higher

8. Map Integration Points

Current: data-driven SVG projection

Module: src/components/officer/ComplaintMap.jsx

  • Mercator projection of complaint coordinates onto an SVG canvas
  • Priority-colored markers (critical/high/medium/low)
  • Click-to-select with detail tooltip
  • Responds to filter changes from the officer filters bar
  • Auto-fits viewport to the complaint bounds with padding

Leaflet swap-in (documented in component)

  1. npm install leaflet react-leaflet
  2. Import Leaflet CSS in styles/index.css
  3. Replace the SVG canvas with <MapContainer> + <TileLayer>
  4. Replace SVG circles with <CircleMarker> using the same priority color map
  5. Replace click handler with Leaflet's eventHandlers={{ click }}
  6. The complaints prop, filter integration, and detail panel remain unchanged

Coordinate system

grievanceUtils.coordsFor() provides coordinates: known demo locations get mapped points from LOCATION_COORDS; unknown locations are scattered deterministically around the city centre using a stable hash of the complaint ID (no jitter between renders).
